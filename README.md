# IFSC Code Finder

A web-based project developed using PHP that allows users to search and find the IFSC (Indian Financial System Code) of bank branches across India.

## Files Included

| File | Description |
| `IFSC FULL.pdf` | Complete project documentation and source code |

## Tech Stack

- PHP
- MySQL (Database)
- HTML, CSS, JavaScript

## Features

- Search bank branch details using IFSC code
- Find IFSC code by bank name, state, district, and branch
- User-friendly web interface
- Database-driven lookup for accurate results

## How to Run

1. Clone the repository:
```bash
   git clone https://github.com/mounika0704/Project---IFSC-Code-Finder-using-PHP.git
```
2. Set up a local server environment (XAMPP/WAMP/MAMP).
3. Place the project folder inside the `htdocs` (or equivalent) directory.
4. Import the database (if provided) into MySQL via phpMyAdmin.
